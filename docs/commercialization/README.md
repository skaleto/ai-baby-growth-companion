## 当前原则

- 先验证 Pro 付费意愿，不急着接支付。
- Pro 第一付费锚点是“少输入、少遗漏、自动整理”，不是单纯多模态或家庭交接。
- 第一阶段使用手动白名单和额度控制。
- 云端模型、OSS 和服务器成本控制在 `¥300-500/月`。
- 不用宝宝数据做广告推荐或商品画像。
- AI 育儿建议只做科普和整理，不替代医生。
