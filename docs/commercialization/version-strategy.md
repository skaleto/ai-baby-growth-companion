# 小宝记 Lite / Free / Pro 变现版本策略

更新时间：2026-05-14

## Summary

小宝记后续商业化优先选择“强信任订阅”路线：先验证家庭是否愿意为更省心的 AI 照护助手长期付费，不优先做导购、广告或专家服务。

版本策略分为三档：

- **Lite 纯客户端版**：最高隐私模式，数据和 AI Key 都由用户自己掌控。
- **标准免费版**：大众家庭默认入口，云端托管数据，提供基础记录和 DeepSeek 纯文本 AI。
- **Pro 会员版**：高频照护家庭的高级 AI 照护助手，提供 Doubao 多模态和更强 Agent 能力。

第一阶段只记录策略和后续会员墙验证方向，不改代码、不接支付、不调整现有功能。

## 版本定位

| 版本 | 核心定位 | 目标用户 | 核心价值 |
| --- | --- | --- | --- |
| Lite 纯客户端版 | 最高隐私模式 | 极度重视隐私、愿意自己配置 API Key 的用户 | 数据不出设备，模型费用自理，产品只提供本地工具能力 |
| 标准免费版 | 大众家庭默认入口 | 需要低门槛记录和家庭同步的普通家庭 | 免费可用、云端托管、基础 AI 文本记录 |
| Pro 会员版 | 高级 AI 照护助手 | 高频记录、多人协作、希望减少照护心智负担的家庭 | 更智能、更自动、更省心的多模态 Agent 和照护复盘 |

## Lite 纯客户端版

### 定位

Lite 是最高隐私模式，强调“本地优先、用户自管、无需云端账号”。它不是默认大众入口，而是给隐私敏感或技术接受度较高的用户选择。

### 数据

- 数据存储在本地设备，不依赖云端账号、家庭邀请码或服务器数据库。
- 第一版不承诺家庭实时共享、多设备同步和云端备份。
- 后续如实现，应优先支持手动导出/导入，用于换机和备份。

### AI

- 用户自行提供模型 API Key。
- 模型调用费用由用户自行承担。
- API Key 应只保存在本机，不上传到小宝记服务器。
- 第一版建议默认支持文本 AI；多模态能力可作为用户自带 Key 的高级配置。

### 能力

- 基础照护记录。
- 基础提醒。
- 基础账本。
- 本地相册。
- 文本 AI 记录和问答。
- 本地数据导出/导入。

### 限制

- 不承诺云端家庭协作。
- 不承诺自动云备份。
- 不承诺跨设备实时同步。
- 用户需要理解并承担 API Key 配置、模型费用和 Key 安全责任。

## 标准免费版

### 定位

标准免费版是大众家庭默认入口，用于降低使用门槛和建立长期信任。免费版必须保持核心可用，不能让用户觉得“不付费就无法记录宝宝”。

### 数据

- 云端家庭托管。
- 支持手机号 + 家庭邀请码登录。
- 支持家庭成员、角色权限和家庭共享数据。
- 小宝资料、照护记录、成长事件、相册、账本按家庭共享；聊天、提醒、记忆、待确认记录按账号隔离。

### AI

- 平台提供 DeepSeek 纯文本模型能力。
- 支持基础文本记录、文本问答和文本提醒/账本解析。
- 不支持图片/视频 AI 理解。

### 能力

- 文本照护记录。
- 基础提醒。
- 基础账本。
- 基础相册。
- 基础趋势和日历。
- 家庭共享记录。
- DeepSeek 纯文本 Agent。

### 限制

- 图片/视频只能作为相册或聊天附件，不进入 AI 多模态理解。
- 多模态识别、高级趋势、周报/月报、更多 AI 配额和更多云相册空间引导到 Pro。

## Pro 会员版

### 定位

Pro 是高频照护家庭的高级 AI 照护助手。收费点不是“模型更贵”，而是“更省心、更智能、更自动”：少漏记、少翻记录、家人同步、关键变化看得懂。

### 数据

- 云端托管。
- 家庭共享。
- 后续可增加更高云相册空间、长期数据备份和高级导出能力。

### AI

- 支持 Doubao 等多模态模型。
- 支持图片/视频理解。
- 支持更强 Agent 能力和更高 AI 使用配额。

### 能力

- 图片/视频理解。
- 相册准入判断。
- 图片/视频辅助育儿问答。
- 高级 Agent 自动记录和多轮追问。
- 周报/月报。
- 趋势洞察。
- 家庭照护复盘。
- 更多 AI 配额。
- 更多云相册空间。

### 收费假设

- 早期建议在 `¥6-12/月` 区间测试。
- 初始价格锚点可为 `¥9.9/月`、`¥68/年`。
- 第一阶段先做会员墙和内测申请，不直接接支付。
- 真实支付放到后续阶段再评估；iOS/Google Play 数字会员需要走平台内购，国内安卓/私域支付单独评估。

## 关键决策

- 商业化优先级：订阅留存优先。
- 信任边界：强信任克制，不用宝宝数据做广告推荐或商品画像。
- 暂不优先做：导购、广告、专家服务、商品推荐。
- 验证方式：先做会员墙和内测申请，不直接接支付。
- Lite 版本：先作为策略和内测入口记录，后续再实现本地存储和用户自带 Key。
- Free / Pro 差异：Free 卖“可用”，Pro 卖“更省心、更智能、更自动”。

## 后续阶段

### 第一阶段：策略记录与付费意愿验证

- 仅记录本文档和后续会员墙方向。
- 不改现有代码。
- 不接真实支付。
- 后续可增加三版本权益页、升级入口、内测申请和点击埋点。

### 第二阶段：三版本权益页

- 展示 Lite / Free / Pro 对比。
- Free 用户触发图片识别、高级趋势、周报/月报、更多 AI 配额时展示 Pro 入口。
- Lite 先作为“加入内测”或“提醒我开放”入口。
- 记录会员页曝光、点击、关闭、申请体验和来源。

### 第三阶段：Lite MVP 评估

- 评估本地 storage adapter。
- 评估本地 API Key 管理。
- 评估本地数据导出/导入。
- 评估客户端直连模型的安全边界、跨端兼容和错误处理。
- 第一版 Lite 不承诺家庭实时共享。

### 第四阶段：真实支付与订阅

- 在付费意愿明确后再接真实支付。
- iOS 数字会员走 Apple In-App Purchase。
- Google Play 渠道走 Google Play Billing。
- 国内安卓渠道、私域支付、微信小程序支付另行评估。
- 支付前需要补齐订阅协议、隐私说明、退款/取消、客服和会员状态同步。
