## 顶层：一句话战略

> **以记录为地基，低焦虑为体感，AI 情感陪伴为灵魂——做疲惫新手父母「随时懂他、不催不评判、一直在」的那个存在。**

巨头的标准答案是"内容 + 社群 + 电商"（[数英网行业观察](https://www.digitaling.com/articles/42837.html)），它们都放弃了"AI 陪伴 × 个性化记录"这个角落。我们的劣势（无社区、无内容、团队小）在这个方向反而是轻量优势。

## 第一层：能力分层（逻辑骨架）

四层，从下到上 = 地基到灵魂。下层是上层的前提，上层是下层的意义。

```
┌──────────────────────────────────────────────────────┐
│  观察层    社区（远期可选，现在不做，只记触发条件）        │
├──────────────────────────────────────────────────────┤
│  延展层    月龄到 3 岁（LTV 命门，主攻验证后启动）         │
├──────────────────────────────────────────────────────┤
│  灵魂层    AI 情感陪伴 × baby 数据关联（差异化主攻）       │  ← 我们赢在这
├──────────────────────────────────────────────────────┤
│  地基层    记录 + 低焦虑反疲劳设计（永远免费、永远在）      │  ← 我们活在这
└──────────────────────────────────────────────────────┘
```

**关键关系**：
- **地基层**是留存的命脉，但不是差异化（人人都做记录）→ 做到"不累"就够，不在这卷功能
- **灵魂层**是差异化的全部 → 资源往这倾斜
- 地基没扎稳之前不堆灵魂（用户连记录都嫌累，谈何陪伴）

## 第二层：阶段路线图

### Phase 0 — 地基巩固 + 反疲劳立心智（进行中）

**目标**：把"记录不累"从一个隐性优势，变成显性的产品宣言和品牌调性。

**关键动作**：
- 把聊天式自然语言记录的"低摩擦"显性化（已有能力，缺叙事）
- 「今日发现」升级为 AI 中枢（已有 plan：`plans/2026-06-01-daily-summary-ai-hub.md` 的 3 件事——色彩编码 stat card / 命名 + 反馈闭环 / 成长接入）
- 排查并移除任何制造焦虑的机制：streaks / 打卡 / 红点 / "你已 N 天没记录"式催促（对标 Huckleberry **显式反 streaks** 的品牌立场）
- 建立"不催、不评判、记不记由你"的文案体系
- 视觉刷新收尾（`specs/2026-05-26-visual-refresh-plan.md` Phase 3 数据可视化）

**成功信号 → 触发 Phase 1**：
- 记录频次稳定不掉、留存不掉
- 用户主观反馈"用着不累"（访谈）
- 「今日发现」有真实重复打开（不是发了没人看）

### Phase 1 — AI 情感陪伴 × baby 数据（主攻，最高优先级）

**目标**：从"信息工具"升级为"懂我的存在"——这是差异化的全部。

**关键动作**：
- **情感场景识别**：聊天里识别焦虑/疲惫/无助/自我怀疑的信号，给到非评判回应
- **与 baby 数据关联**：陪伴不空洞，挂在真实记录上。例："你说累——今天宝宝夜醒 3 次、你只睡了 4 小时，换谁都扛不住"（懂我 = 数据 + 共情）
- **「今日发现」加情感维度**：不只是"奶量比昨天少"，也有"这周你哄睡 6 次都成功了，你做得很好"
- **守住非诊疗边界**（硬约束）：不诊断、不开处方、不替代医生；识别到高风险（疑似产后抑郁等）温和引导专业资源
- **「一直在」的设计**：主动但不打扰的触点（晚间一句"今天辛苦了"而非"你还没记录"）

**成功信号 → 验证差异化成立**：
- 情感对话被自然触发的比例
- 用户主观"被懂了"的反馈
- 留存提升 + 愿意为"陪伴"付费的信号（对标 Joy $12/mo、Huckleberry <$5/mo 验证非电商订阅可行）

**这一层是我们 vs 巨头的胜负手**：宝宝树「米卡 AI」（2025-05 已上线）会反扑，要在它做深之前占住"AI 情感陪伴"心智。

### Phase 2 — 月龄延展到 3 岁（LTV 命门，主攻验证后启动）

**目标**：解决结构性短板——0-1y 窗口 < 2 年，LTV 撑不起服务器+模型成本。

**关键动作**：
- 数据模型 / 里程碑 / 成长曲线延展到 3 岁（覆盖入园前后）
- 陪伴叙事随月龄自适应（孕期焦虑 → 新生儿手忙脚乱 → 幼儿期不同）
- 对标：Huckleberry 0-5y、宝宝树 0-6y 都覆盖更长

**触发条件**：Phase 1 验证有真实用户因"陪伴"而留存/付费——**没验证前不延展，否则失焦**。

### Phase 3+ — 社区（远期可选，现在只观察）

**现在不做**。记录触发条件，等以下信号出现再评估：
- 用户自发产生 UGC 需求（在聊天里问"别人家宝宝也这样吗"）
- 有了足够用户密度能冷启动
- 灵魂层（AI 陪伴）已稳固，社区是增量不是救命稻草

## 第三层：贯穿全程的设计原则（不可妥协）

| 原则 | 含义 | 反面教材 |
|---|---|---|
| **反疲劳** | 不催、不评判、不 streaks、不红点焦虑；记不记由你 | 多数记录类 App 用打卡/连续天数绑架用户 |
| **非诊疗边界** | 不诊断、不开药、不替代医生；高风险温和转介专业资源 | Wysa 是临床路径（B2B2C），我们是 C 端陪伴不能越界 |
| **隐私优先** | baby 数据 + 情感对话高敏感；端侧/不滥用/可导出可能成护城河 | Consumer Reports 已 flag 母婴 App 普遍隐私问题 |
| **轻而私密** | 不堆功能、不做重资产；轻和私密是我们对 Joy（人类专家重资产）的反差优势 | — |

## 明确不做清单（防 scope creep）

| 不做 | 理由 |
|---|---|
| ❌ 专家 IP / 医生 KOL | 育学园 + 崔玉涛 + 新东方资本几亿打过，正面拼必败 |
| ❌ 知识付费 / 课程 | 天花板低、复购弱、月龄过窗即流失（年糕妈妈已验证困境） |
| ❌ 电商 / 导购 / 商城 | 已主动放弃，非电商订阅已被海外验证可行 |
| ❌ 单点垂直（睡眠/喂养专项） | Huckleberry/Napper/Glow 已占，与"陪伴"定位冲突 |
| ❌ 追求"最强育儿 AI 模型" | Joy 带 $14M 在做；我们拼调性 + 跨域 + 记忆，不拼模型 size |
| ⏸️ 社区 | 暂不做，远期观察（见 Phase 3+） |

## 需后续拍板的开放问题（不阻塞 Phase 0/1 启动）

1. **AI-only vs Hybrid**：Joy 明确选 AI + 人类专家，理由"AI 独行不够"。我们坚持纯 AI 还是远期接远程儿保/育婴师？（影响 Phase 1 后半段）
2. **诊疗边界的具体红线**：进情感陪伴必碰心理健康，"不诊疗"的产品/法务红线怎么划？（Phase 1 启动前要有结论）
3. **Subscription 时机**：之前主张"验证阶段全员免费"，研究显示海外都付费墙。什么指标触发上墙？（Phase 1 验证期决定）
4. **隐私是护城河还是过度顾虑**：端侧/不上传/可导出做到什么程度？（贯穿全程，越早定越好）
