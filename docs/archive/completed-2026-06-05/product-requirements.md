# AI宝宝成长伙伴 App 需求文档

## 1. 产品概述

### 1.1 产品定位

AI宝宝成长伙伴是一款面向孕期到宝宝 1 岁家庭的多模态育儿记录 App。它不是单纯的相册、闹钟或育儿百科，而是一个通过每天 5 分钟聊天，自动整理宝宝成长、照护数据、提醒事项和家庭记忆的 AI 伙伴。

### 1.2 一句话描述

爸妈只要像聊天一样发照片、视频、语音或文字，AI 自动理解宝宝今天发生了什么，生成成长记录、提取喂养睡眠数据、创建提醒，并在需要时结合宝宝历史给出建议。

### 1.3 目标用户

- 孕期到宝宝 1 岁的新手妈妈。
- 需要共同照护宝宝的爸爸、老人或其他家庭成员。
- 希望记录宝宝成长，但没有精力每天填写复杂表格的家庭。

### 1.4 核心痛点

- 宝宝信息分散在相册、备忘录、疫苗本、聊天群和纸质记录里。
- 新手爸妈很累，无法长期坚持手动填写喂奶、睡眠和成长日志。
- 重要成长瞬间容易被拍下来却没有上下文，例如第一次站、第一次说话。
- 提醒事项不只是闹钟，还需要追踪是否已完成。
- 家长遇到闹觉、厌奶、哭闹等问题时，希望建议能结合自己宝宝的历史，而不是通用答案。

## 2. MVP 范围

### 2.1 MVP 目标

第一版围绕一个核心体验：

> 今天跟 AI 聊 5 分钟，宝宝的一天就被整理好了。

### 2.2 MVP 必须包含

- 多模态输入：文字、语音、照片；视频先支持上传和摘要入口。
- 自动生成日记：温柔的成长记录和结构化标签。
- 宝宝档案：预产期、出生日期、昵称、地区、喂养方式、过敏史、主要照护人。
- 每日照护数据：奶量、喝奶次数、睡眠时长、夜醒次数、辅食、便便、体温、情绪和健康备注。
- 里程碑识别：第一次胎动、出生、第一次笑、第一次翻身、第一次坐、第一次站、第一次说话等。
- 提醒系统：疫苗、日常安排、自定义事项，并支持完成状态追踪。
- AI 记忆：保存作息偏好、哄睡方式、过敏信息、家长关注点。
- 家庭共享基础能力：至少在产品设计上支持另一位照护人共同查看和补充记录。

### 2.3 暂不做或后续增强

- 深度视频理解。
- 医生或儿保记录的完整 OCR 归档。
- 完整家庭权限体系。
- 老人模式和爸爸任务分配。
- 自动生成周报、月报和成长相册。
- 医疗诊断、用药判断或替代医生的建议。

## 3. 核心功能需求

### 3.1 每天 5 分钟聊天入口

用户可以通过文字、语音、照片和视频向 App 记录当天内容。AI 需要从输入中自动判断内容类型，包括成长事件、喂养、睡眠、提醒、健康、辅食、情绪和家庭记忆。

AI 只在必要时追问少量问题，例如：

- 这次喝了多少 ml？
- 这是第一次自己站起来吗？
- 疫苗接种时间需要我提醒到哪一天？

### 3.2 成长时间线

系统按日期生成宝宝成长时间线。每条成长记录包含标题、日期、摘要、标签、是否为第一次，以及关联照片或视频。

典型记录示例：

> 今天小宝第一次扶着沙发站起来，大约坚持了 8 秒，妈妈拍下了这个瞬间。

### 3.3 AI 记忆与提醒

用户可以用自然语言设置提醒和长期记忆。

示例：

- 每天晚上 8 点提醒我给小宝洗澡。
- 下周二提醒我带小宝去社区医院打疫苗。
- 小宝最近 10 点左右容易闹觉。
- 小宝喜欢白噪音和轻拍。

提醒不仅需要创建，还需要支持完成状态追踪，例如“今晚洗澡做了吗？”。

### 3.4 喂养、睡眠和护理日志

系统从聊天中提取结构化照护数据，减少用户填表负担。

需要支持的信息：

- 喂养：奶量、喝奶次数、母乳/奶粉/混合喂养。
- 睡眠：睡眠时长、夜醒次数、哄睡难度。
- 辅食：食材、过敏风险、已尝试食材。
- 护理：便便、体温、哭闹、吐奶、湿疹、用药备注。

系统应能生成趋势摘要，例如：

- 过去 7 天夜醒次数变多。
- 今天奶量比平时少。
- 最近 22:00 左右更容易闹觉。

### 3.5 育儿辅助内容

系统提供低风险、记录型和提醒型辅助能力：

- 疫苗提醒：按宝宝出生日期和地区生成提醒，具体接种安排以社区医院或医生为准。
- 辅食菜谱：按月龄、过敏史和已尝试食材推荐。
- 哄睡音乐和白噪音：结合宝宝偏好保存常用方案。
- 育儿问答：宝宝闹觉、厌奶、哭闹时，结合历史记录给出可能原因和安全建议。

健康、疫苗、用药相关内容必须明确边界：只做记录、提醒和常识建议，不替代医生诊断。

## 4. 数据模型

### 4.1 BabyProfile

宝宝档案。

- 昵称
- 阶段：孕期或已出生
- 预产期
- 出生日期
- 所在地区
- 喂养方式
- 过敏史
- 主要照护人

### 4.2 DailyConversation

每日聊天记录。

- 消息角色：家长或 AI
- 文本内容
- 语音转文字结果
- 关联照片、视频或音频
- AI 追问
- 用户确认内容
- 标签

### 4.3 GrowthEvent

成长事件。

- 事件类型
- 标题
- 发生日期
- 摘要
- 是否第一次发生
- 关联媒体类型
- 标签

### 4.4 CareLog

照护日志。

- 日期
- 奶量
- 喝奶次数
- 睡眠时长
- 夜醒次数
- 哄睡难度
- 辅食
- 便便
- 体温
- 健康和护理备注

### 4.5 Reminder

提醒事项。

- 标题
- 时间描述
- 类型：疫苗、日常、护理、自定义
- 重复规则
- 状态：未完成、已完成、错过
- 完成历史

### 4.6 Memory

AI 长期记忆。

- 记忆内容
- 类型：作息、偏好、健康、照护人、家长关注点
- 置信度
- 更新时间

## 5. AI 能力需求

### 5.1 当前 MVP

当前 MVP 通过本地规则模拟 AI 解析能力，主要用于验证产品体验和信息结构。

已覆盖：

- 中文文本解析。
- 里程碑识别。
- 喂奶和睡眠数据提取。
- 提醒识别。
- 长期记忆生成。
- 基于最近日志的简单建议。

### 5.2 真实 AI 版本

后续接入 OpenAI GPT 模型时，建议采用 App + 后端 + OpenAI API 架构。

移动 App 不应直接保存 OpenAI API Key。推荐流程：

1. App 上传文字、语音、图片或视频到业务后端。
2. 后端调用 OpenAI API 做多模态理解和结构化抽取。
3. 后端返回 GrowthEvent、CareLog、Reminder、Memory 和 AI 回复。
4. App 展示结果并允许用户确认或编辑。

需要的 AI 能力：

- 语音转文字。
- 图片理解，例如宝宝动作、疫苗本、辅食图片。
- 视频摘要和关键片段理解。
- 结构化信息抽取。
- 长期记忆读写。
- 基于宝宝历史的个性化育儿建议。

## 6. 测试场景

### 6.1 里程碑记录

输入：

> 今天小宝第一次自己扶着沙发站起来了。

期望：

- 生成成长事件。
- 标记为第一次站立。
- 加入成长时间线。
- AI 提醒用户确认是否保存为重要里程碑。

### 6.2 提醒创建

输入：

> 晚上 8 点提醒我给小宝洗澡。

期望：

- 创建日常提醒。
- 时间显示为晚上 8 点。
- 支持标记完成。
- 手机端尝试注册本地通知。

### 6.3 喂养睡眠提取

输入：

> 今天喝奶 5 次，每次大概 120ml，晚上醒了 3 次。

期望：

- 记录喝奶 5 次。
- 计算奶量约 600ml。
- 记录夜醒 3 次。
- 更新今日照护概览。

### 6.4 个性化建议

输入：

> 为什么这两天小宝更难哄睡？

期望：

- 参考最近睡眠、夜醒、哄睡难度和 AI 记忆。
- 给出低风险建议。
- 提醒异常情况应联系医生。

### 6.5 疫苗记录

输入：

> 下周二提醒我带小宝去社区医院打疫苗。

期望：

- 创建疫苗提醒。
- 显示安全提示：具体安排以社区医院或医生为准。
- 加入提醒追踪列表。

## 7. 安全与合规边界

- 不提供医疗诊断。
- 不提供明确用药决策。
- 疫苗、发热、过敏、哭闹异常等内容必须提示以医生或社区医院安排为准。
- 宝宝照片、视频、语音和健康数据属于敏感家庭数据，真实产品必须设计账号、加密、权限和删除机制。
- OpenAI API Key 必须保存在服务端，不能内置到 Android 或 iOS App 中。

## 8. 成功指标

- 用户每天能在 5 分钟内完成宝宝记录。
- 大部分记录通过聊天自动生成，不依赖复杂表单。
- 用户能在成长时间线中快速找到重要里程碑。
- 提醒事项能被创建、追踪和完成。
- 用户提问时，AI 能引用宝宝历史信息，而不是只给通用建议。
