# 文档归档说明

本目录存放已经完成、被当前路线覆盖、或只用于追溯历史决策的文档。后续 agent 默认不应从这里选择产品方向或实现范围。

2026-06-06 起，5 月决策文档和旧 daily-summary / 视觉刷新 / PRD 归档已从工作区删除。需要历史细节时用 git 历史追溯；当前实现不得再依赖这些旧文档。

当前应优先读取的入口统一维护在 `harness/project-index.md`（Read First / Active Docs Map），此处不再重复，避免多处同步。

归档规则：

- 已完成的一次性任务记录只有在确有追溯价值时才放入 `docs/archive/completed-YYYY-MM-DD/`；过时决策文档可直接删除。
- 市场调研和竞品研究继续放入 `docs/research-archive/`。
- 脚本会覆盖或追加的报告文件仅在当前仍作为证据时保留；过期云端 E2E 结果可删除，脚本会在下次运行时再生成。
